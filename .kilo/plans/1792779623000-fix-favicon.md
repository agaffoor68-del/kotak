# Plan: Fix favicon.ico 404

## Problem
/favicon.ico returns 404 causing dashboard load failures.

## Root Cause
No favicon.ico in web/public/ directory. Next.js/Browser looks for /favicon.ico by default.

## Solution
1. Add favicon.ico to web/public/ (can copy from icon.svg or create)
2. Update layout.tsx metadata to include favicon
3. Ensure it's served correctly

## Files to modify
- web/public/favicon.ico (create/copy)
- web/app/layout.tsx (update metadata)

## Implementation
Copy icon.svg as favicon.ico or add to metadata.icons with .ico
